# 🏊‍♂️ Nadador Principiante: El equipo que a mí me salvó en la alberca

## 📝 Descripción
¿Qué hace tu recomendador?  
Es una plataforma web personal y directa diseñada para ayudar a quienes van empezando en el mundo de la natación. El sitio recopila una selección honesta y probada de equipo esencial (goggles, aletas, tablas y accesorios) para evitar la frustración inicial, mejorar la comodidad en los entrenamientos y ayudar a los nuevos nadadores a perder el miedo a la alberca de forma práctica y sin rodeos. Incluye carruseles interactivos, detalles técnicos y enlaces directos de compra.

## 🛠️ Tecnologías utilizadas

Este proyecto fue desarrollado utilizando las siguientes tecnologías y herramientas:

* **HTML5:** Estructura semántica de la página web.
* **CSS3:** Estilos personalizados, diseño adaptativo y efectos visuales.
* **Bootstrap (v5.3):** Framework de diseño responsivo para la barra de navegación, tarjetas, cuadrículas y componentes interactivos.
* **JavaScript:** Lógica interna y control de componentes de Bootstrap (como los carruseles de imágenes).
* **Git:** Sistema de control de versiones para el seguimiento de cambios en el código local.
* **GitHub:** Plataforma de alojamiento de código y despliegue del sitio web mediante **GitHub Pages**.
* **IA utilizada:** Asistencia de inteligencia artificial para la estructuración del código, optimización de estilos CSS (corrección de carruseles y diseño responsive) y redacción técnica.
